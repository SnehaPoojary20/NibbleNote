# NibbleNote 🚀

NibbleNote is a scalable restaurant and café discovery platform that enables users to share reviews, ratings, images, and location-based experiences. The platform focuses on fast content discovery, efficient location querying, and community-driven recommendations.

---

# 🌟 Why This Project Matters

NibbleNote simplifies restaurant discovery by helping users explore authentic experiences shared by the community. Users can discover places based on ambience, food quality, ratings, and reviews instead of relying only on generic listings.

The platform is designed to support scalable user-generated content, optimized search performance, and location-aware discovery workflows.

---

# 🛠️ Engineering Focus

### High-Performance Search
Implemented MongoDB indexing and optimized database queries for faster restaurant discovery and reduced response latency.

### Location-Based Discovery
Integrated geospatial querying to enable efficient nearby restaurant and café recommendations.

### Scalable Backend Architecture
Built modular REST APIs using Node.js and Express.js for scalable user, review, and content management.

### Secure Authentication
Implemented JWT-based authentication and authorization workflows for secure session management.

### Responsive User Experience
Designed responsive frontend components for seamless review posting, image uploads, profile management, and content browsing.
