# NibbleNote – AI & Systems Backend ⚙️

This is the core engine of NibbleNote, designed with a focus on **low-latency discovery** and **AI orchestration**.

## 🧠 System Architecture & Design
- **AI Layer:** Integrated **LangChain** to orchestrate LLM calls. Implemented **Semantic Caching** to reduce API costs by storing and reusing vector-matched AI responses.
- **Vector Search:** Converts restaurant metadata into embeddings; uses **Pinecone** for nearest-neighbor search logic.
- **Geospatial Optimization:** Implemented a `GEOADD` and `GEORADIUS` workflow in **Redis** to bypass traditional disk-heavy database lookups for location data.
- **Security:** Implemented a multi-layered security approach:
  - Refresh Token Rotation to prevent replay attacks.
  - Middleware-driven Role-Based Access Control (RBAC).
  - Rate Limiting (PulseGuard integration) to prevent API abuse.

## 📡 API Design
- **RESTful Architecture:** Stateless endpoints with consistent HTTP semantics.
- **Validation:** Joi/Zod driven request validation to ensure data integrity before reaching the controller layer.

## 🛠️ Setup & Environment
1. `npm install`
2. Configure `.env` (Include `PINECONE_API_KEY`, `GEMINI_API_KEY`, and `REDIS_URL`)
3. `npm run dev`
